## Introdução

O SubRider é um sistema completo para gestão de oficinas de motocicletas. Com ele, você pode:
- Gerenciar cadastro de proprietários e suas motos
- Criar e acompanhar ordens de serviço
- Registrar medições e serviços realizados
- Gerar relatórios e históricos

## Primeiros Passos

### Acessando o Sistema

1. Abra seu navegador e acesse o endereço do sistema
2. Na tela de login, insira seu usuário e senha
3. Clique em "Entrar"

### Navegação Básica

- O menu principal está sempre disponível no topo da tela
- Use a barra de pesquisa para encontrar rapidamente proprietários, motos ou ordens de serviço
- O botão "Voltar" retorna à tela anterior
- O botão "Sair" encerra sua sessão com segurança

## Funcionalidades

### Gestão de Proprietários

#### Cadastrando um Novo Proprietário

1. No menu, clique em "Proprietários" > "Novo Proprietário"
2. Preencha os campos obrigatórios:
   - Nome completo
   - CPF (será validado automaticamente)
   - Telefone
   - Email
3. Preencha os campos opcionais:
   - Endereço
   - Cidade
   - Estado
   - CEP
4. Clique em "Salvar"

#### Editando um Proprietário

1. Na lista de proprietários, localize o registro desejado
2. Clique no ícone de edição (lápis)
3. Faça as alterações necessárias
4. Clique em "Salvar"

### Gestão de Motos

#### Cadastrando uma Nova Moto

1. No menu, clique em "Motos" > "Nova Moto"
2. Preencha os campos obrigatórios:
   - Placa
   - Marca
   - Modelo
   - Ano
   - Proprietário
3. Preencha os campos opcionais:
   - Quilometragem
   - Cor
   - Observações
4. Clique em "Salvar"

#### Transferindo Proprietário

1. Na lista de motos, localize a moto desejada
2. Clique no ícone de histórico
3. Na tela de histórico, clique em "Transferir Proprietário"
4. Selecione o novo proprietário
5. Adicione uma observação se necessário
6. Clique em "Transferir"

### Ordens de Serviço

#### Criando uma Nova Ordem

1. No menu, clique em "Ordens de Serviço" > "Nova Ordem"
2. Selecione a moto (ou proprietário)
3. Adicione os serviços a serem realizados
4. Registre as medições iniciais
5. Clique em "Criar Ordem"

#### Acompanhando uma Ordem

1. Na lista de ordens, localize a ordem desejada
2. Clique no número da ordem para ver os detalhes
3. Use os botões de status para atualizar o andamento:
   - Em Análise
   - Em Andamento
   - Aguardando Peças
   - Concluído
   - Entregue

#### Finalizando uma Ordem

1. Registre todas as medições finais
2. Adicione fotos do serviço (se necessário)
3. Atualize o status para "Concluído"
4. Gere o relatório de serviço
5. Após a entrega, atualize para "Entregue"

## Perguntas Frequentes

### Como recuperar minha senha?
Entre em contato com o administrador do sistema para resetar sua senha.

### Como corrigir um erro em uma ordem de serviço?
Ordens de serviço podem ser editadas enquanto não estiverem no status "Entregue".

### Como encontrar o histórico de uma moto?
Na lista de motos, clique no ícone de histórico para ver todas as informações, incluindo proprietários anteriores e ordens de serviço.

### Como gerar relatórios?
Use o menu "Relatórios" e selecione o tipo desejado:
- Serviços por período
- Histórico por moto
- Histórico por proprietário
- Medições comparativas
